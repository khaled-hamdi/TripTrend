# TripTrend Ver 2.0

In Admin Panel > Daily Import, use **Build Price_History from HOTEL_RAW tabs already in Google Sheets**, review the preview, and approve it once. This migrates the existing hotel tabs into the analytics tables without re-uploading the daily hotel workbook.

This package includes page-level data scope and city/date controls, cached Google Sheets reads, external flights/events/city prices, durable campaign likes from Engagement_Events, and the V2 admin import path.
